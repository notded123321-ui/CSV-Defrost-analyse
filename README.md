# Heat Pump Defrost Cycle Analysis

## About the Project

This project investigates how the time between data recordings affects the number of heat pump defrost events that can be observed.

The aim was to find out whether recording data less frequently would cause short defrost events to be missed.

This is an independent research investigation using real data from the US National Renewable Energy Laboratory (NREL).

## Dataset

The dataset comes from the NREL project *Field Validation of Air-Source Heat Pumps for Cold Climates*.

For this investigation, Site 7 was analysed using Python.

- Total recordings: 1,441,132
- Original published recording interval: 30 seconds
- Defrost operating mode: 6
- Identified defrost events: 3,735

**Original dataset:** https://heatpumpdata.energy.gov/node/84176

The original CSV file is not included in this repository due to its large size.

## Methodology

The Python script `CSV defrrost extract.py` reads the original NREL CSV file and identifies defrost events using operating mode 6.

An event is counted if it contains at least four consecutive 30-second readings labelled as defrost.

The program then simulates recording intervals of:

- 30 seconds
- 1 minute
- 5 minutes
- 15 minutes

Different recording start times are tested to determine how many of the original events would still be observed.

The average percentage of events observed is calculated for each interval.

## Results

| Recording Interval | Events Observed | Events Missed |
|---|---|---|
| 30 seconds | 100.00% | 0.00% |
| 1 minute | 100.00% | 0.00% |
| 5 minutes | 76.64% | 23.36% |
| 15 minutes | 31.90% | 68.10% |

The results show that longer recording intervals cause more defrost events to be missed.

At 15-minute intervals, approximately 68% of the identified events were missed.

## Repository Files

**`CSV defrrost extract.py`**

The main Python script used to identify defrost events and calculate the observation percentages.

**`defrost_results.txt`**

Contains the numerical results generated by the analysis.

## How to Run the Code

1. Download the NREL Site 7 dataset from the official source.
2. Extract the ZIP file.
3. Place `site_7_hp_data_all.csv` in the same folder as `CSV defrrost extract.py`.
4. Open Command Prompt in that folder.
5. Run:

   `python "CSV defrrost extract.py"`

6. The program will generate a file named `defrost_results.txt` containing the results.

The program uses Python's built-in `csv`, `datetime` and `statistics` modules. No additional libraries are required.

## Limitations

The operating modes were estimated by the original NREL researchers. This investigation measures whether the defrost-labelled events remain visible when the recording interval increases. It does not independently confirm physical defrost events using temperature or power measurements.

Only Site 7 was analysed, so the results may not apply to all heat pumps or climates.

Events containing fewer than four consecutive 30-second defrost readings were excluded.
